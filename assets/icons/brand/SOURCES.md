# Источники фирменных знаков

Все знаки скачаны с официальных ресурсов брендов 23.09.2026. Использование — по
правилам каждого бренда: цвет плашки и пропорции знака не меняем, знак не
перерисовываем, охранное поле держим не меньше рекомендованного.

| Бренд | Файл | Источник |
|---|---|---|
| VK | `vk-official.svg`, `vk-glyph-white.svg` | архив «Logo_VK» с vk.company/data/VK-logo (`SVG/Blue/VK_logo_Blue_512x512.svg`) |
| Telegram | `telegram-official.svg`, `telegram-glyph-white.svg` | telegram.org/img/t_logo.svg |
| Одноклассники | `ok-official.svg`, `ok-glyph-white.svg` | брендбук insideok.ru → «Логотип ОК» → `Vector/RGB/OK orange compact.svg` |
| Rutube | `rutube-official.svg` | static.rtbcdn.ru (официальный CDN Rutube) |
| MAX | `max-white-official.svg` | брендбук go.max.ru/brandbook, файл «Max white» |
| Mastercard, «Мир», СБП | `mastercard-official.svg`, `mir.svg`, `sbp.svg` | Викисклад / НСПК |

`*-official.svg` — знак целиком, как его отдаёт бренд (с фирменной плашкой).
`*-glyph-white.svg` — из него вырезан только белый знак, без плашки: в макете
плашку заменяет круглая кнопка фирменного цвета.

Фирменные цвета плашек: VK `#0077FF`, Telegram `#2AABEE` (верх официального
градиента, плоская заливка), Одноклассники `#FF7700`, Rutube `#100943`,
MAX `#8114FF`.

Устаревшие файлы (`vk.svg`, `telegram.svg`, `odnoklassniki.svg` из набора Simple
Icons) оставлены для истории; в макетах используются официальные.
