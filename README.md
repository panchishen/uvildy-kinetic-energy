# Увильды — «Энергия движения»

Лендинг программы «Энергия движения» — тендерный образец для курорта «Увильды».
Чистые HTML + CSS (токены) + JS, без сборщиков. Источники: макет Figma,
`02-design/ui-kit.md`, `00-docs/content-map.md` (в корне проекта, не в этом репозитории).

## Стек

- HTML5, CSS-переменные (токены темы), ванильный JS.
- Анимации: GSAP 3.13 + ScrollTrigger с CDN jsDelivr (`js/motion.js`), уровень «спокойный»; без GSAP страница статична.
- Без npm/сборщиков: страница открывается напрямую любым статик-сервером.

## Структура

```
index.html          — тема A «Клиника у озера» (по умолчанию)
b/index.html         — тема B «Тёплый курорт» (генерируется, руками не править)
css/tokens.css        — токены темы A + общая сетка/шкала
css/themes/b.css      — переопределения токенов для темы B ([data-theme="b"])
css/base.css           — сброс, типографика
css/layout.css          — контейнер, сетка, z-слои
css/components.css       — переиспользуемые компоненты (кнопки, шапка, футер…)
css/blocks.css            — стили конкретных блоков страницы
css/responsive.css        — адаптив: ≤1247 (1024), ≤1023 (768), ≤767 (375), <360
js/main.js                 — топбар, мега-меню, шапка, слайдеры, аккордеоны, формы, мессенджеры, переключатель тем
js/motion.js               — появление блоков при прокрутке (GSAP + ScrollTrigger), prefers-reduced-motion
tools/build-theme-b.js      — собирает b/index.html из index.html
tools/build_videos.py       — пережимает ролики ../assets/video/*.mp4 в assets/video/ (без звука, под размер блока)
tools/build_images.py       — собирает assets/img/*.webp (1x и @2x для ретины) из исходников ../assets/img/*.jpg по tools/images.json
assets/                     — иконки, лого, изображения, видео
```

## Две темы

Разметка общая. Правки вносятся только в `index.html`, затем:

```bash
node tools/build-theme-b.js
```

Скрипт подставляет `data-theme="b"`, шрифты Lora + Golos Text, пути `../` и фото `-b`.
Переключатель «Вариант 1 / Вариант 2» справа вверху — только для презентации.

## Картинки

Исходники (jpg) лежат вне репозитория, в `../assets/img/`. После замены исходника:

```bash
python tools/build_images.py
node tools/build-theme-b.js
```

У каждой картинки две версии: `name.webp` (под самый большой размер блока на всех ширинах) и `name@2x.webp` для ретины, в разметке — `srcset="… 2x"`. Нужен Pillow с WebP.

## Видео

Исходные ролики — в `../assets/video/`: `slot-a|b.mp4` (свой на тему) или `slot-n.mp4` (один на обе темы, цвет подгоняется под обложку темы). Для сайта: `python tools/build_videos.py` (ffmpeg из PATH или переменной `FFMPEG`), затем `node tools/build-theme-b.js`.
Видео лежит поверх обложки-картинки и грузится только при первом запуске. Без речи (первый экран, блоки 5, 9, 17, 19) — по кругу, пока блок на экране;
с речью (блок 3, отзывы, подкасты) — по кнопке «Видео». Звук выключен везде.

## Локальный просмотр

Любой статик-сервер из этой папки, например:

```bash
python -m http.server 8765
```

и открыть `http://localhost:8765/`.

## Статус

Десктоп 1440 обеих тем сверстан и сверен с макетом (фреймы 98-2 и 127-1424).
Адаптив 1024 / 768 / 375 (мобильного макета нет — раскладки по решениям в decisions.md),
анимации «спокойный». Lighthouse мобайл: 96–99 / 100 / 100 / 100 (сервер с gzip, как GitHub Pages).
